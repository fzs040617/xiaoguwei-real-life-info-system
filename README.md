# 小谷围岛广州大学城真实生活信息共建系统

面向小谷围岛 / 广州大学城真实生活信息的本地共建、线索提交、审核、地图、路线、历史记录、备份和管理系统。

## 当前状态

- 本项目目前作为 private repository 备份和维护。
- 不建议 public。
- 数据库、本地备份、虚拟环境、IDE 配置不纳入仓库。
- 本文档不记录 token、密码、密钥或其他敏感凭据。

## 目录结构

```text
01_后端服务                         FastAPI 后端服务
02_前端页面                         前端 HTML/CSS/JS 页面
03_项目文档                         项目说明文档
04_测试数据                         测试相关资料
05_文件存储                         文件存储目录
项目交接与续接总文档.md             最重要的续接文档
小谷围岛广州大学城真实生活信息共建系统_续接文档.md  原续接文档
打开后端.bat                        本地后端启动脚本
```

## 本地启动方式

1. 双击 `打开后端.bat`。
2. 后端默认地址为 `http://127.0.0.1:8000`。
3. API 文档为 `http://127.0.0.1:8000/docs`。
4. 前端从 `02_前端页面/index.html` 进入。

## 安全说明

- 不上传数据库文件。
- 不上传 `.env`。
- 不上传 zip 备份。
- 不上传 `.idea/`。
- 不上传虚拟环境。
- 不记录 token、密码和密钥。
- 仓库建议保持 private。

## 开发流程

1. 每次修改前先读两份续接文档。
2. 修改后更新 `项目交接与续接总文档.md`。
3. 完成本地测试。
4. 运行 `git status`。
5. 执行 `git add`。
6. 执行 `git commit`。
7. 执行 `git push`。

## 当前维护原则

- 小步修改。
- 低风险。
- 不大范围重构。
- 不新增 `public-nav.js`。
- 不随意改顶部导航。
- 不直接操作真实数据库中的危险数据。
