新增采集源

这里用于添加公开 RSS / JSON API / HTML 页面，或合法授权 CSV / JSON 数据源。

1填来源名称、平台、地址
2设规则类型、启用、授权说明
3保存到采集篮等待预览和审核

第一版只支持公开可访问的数据源，不处理登录、验证码、私密内容、付费墙或需要特殊授权的接口。 不要填写平台账号、cookie、token、密钥。

系统支持每天自动接入合法授权数据源。小红书、美团、大众点评等平台数据必须来自官方授权、商家授权导出或合法数据服务商；系统不会绕过登录、验证码或反爬。

粘贴采集源配置

可粘贴名称、平台类型、数据源类型、数据地址、授权说明等信息，系统会自动填入下方表单。

智能识别

授权每日更新

仅运行已经配置好的合法授权数据源，本入口不会抓取平台站点、不会使用 cookie、token 或账号环境。

适用于官方授权、商家后台导出、合法数据服务商或本地授权 CSV / JSON 目录。运行后新增条目会进入采集条目列表，仍需人工审核后再流转。

授权源提示
  • 不直接请求小红书、美团、大众点评等平台页面。
  • 不填写真实 token、cookie、密钥或账号密码。
  • 数据包 URL 只接受 http/https，内容应为授权 CSV / JSON 数据包。
  • 本地目录源只读取用户合法提供的 CSV / JSON 文件。

工作流

公开信息先入篮，再审核

  1. 1配置来源填写公开 URL、平台和类型
  2. 2识别内容预览或手动摘录公开信息
  3. 3进入采集条目状态保持 new，等待处理
  4. 4人工转线索审核后再进入线索库
合规边界

只处理公开或授权内容

  • 不登录平台，不使用 cookie。
  • 不绕验证码，不绕反爬。
  • 平台数据只接入官方授权、商家导出或合法服务商数据包。
  • 采集结果人工审核后再入库。
