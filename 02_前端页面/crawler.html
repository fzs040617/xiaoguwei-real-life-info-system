外部平台采集管理

配置公开 RSS、公开 API、公开 HTML 列表页的每日采集

新增采集源

这里用于添加 RSS / JSON API / HTML 页面采集源，需要填写 URL。

第一版只支持公开可访问的数据源，不处理登录、验证码、私密内容、付费墙或需要特殊授权的接口。 不要填写平台账号、cookie、token、密钥。

美团、大众点评、小红书等平台通常涉及登录、动态渲染、风控或官方授权接口。本系统第一阶段不绕过登录、验证码、反爬，也不使用账号 cookie。若要接入此类平台，应使用官方开放平台、合作授权 API，或通过人工导入公开链接/文本的方式进入审核流程。
